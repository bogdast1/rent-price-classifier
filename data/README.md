# Podaci

Ovaj folder namerno ne sadrzi `rent.csv` jer licenca Kaggle dataset-a nije
eksplicitno potvrdjena za redistribuciju.

Dostupan je na:
https://www.kaggle.com/datasets/iamsouravbanerjee/house-rent-prediction-dataset

Cuva se kao `data/rent.csv` (4746 redova, kolone: Posted.On, BHK, Rent,
Size, Floor, Area.Locality, City, Furnishing.Status, Tenant.Preferred,
Bathroom, Point.of.Contact).
